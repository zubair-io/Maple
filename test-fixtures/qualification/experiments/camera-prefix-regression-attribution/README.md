# Source35 regression attribution

Every one of the 29 new source35 failures passes the frozen source33 control. Adding the positive-chroma green-support guard alone produces 16 failures. Metadata-balanced AMaZE produces 9 more failures independently of the guard, and combining it with the guard produces 4 additional failures.

The 13-case prefix cohort was independently run with and without the local-highlight hue change. Both variants fail the same 9 cases and pass the same 4, so local recovery does not explain the extra threshold failures in this cohort. Exact metric arrays are retained; this does not claim identical output pixels or complete-suite safety.

All binary hashes and immutable input sets were verified by the controllers. These are attribution cohorts rather than final gates.

A broad guard exception for all measured-value increases was rejected by an opposing physical Hasselblad witness. The narrower measured-floor trial permits such an exception only below every nearest measured target sample; both opposing physical anchors must pass before expanded controls. No production adoption is claimed here.
