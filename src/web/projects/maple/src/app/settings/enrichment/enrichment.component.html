Geocode worker

Reverse-geocodes EXIF GPS coordinates against a self-hosted Nominatim instance. Cluster of photos at the same place share one API call via the lat/lon cache.

Empty disables geocoding. When the worker is enabled, the server health-checks the URL on save and rejects unreachable values.

Describe worker

Local vision-LLM via Ollama. Runs qwen2.5vl:7b against the 1280-px preview cache and produces a structured caption plus the OCR text for each asset.

Empty uses the default http://localhost:11434. Point at a remote Ollama if the model lives on a different machine.

Face detection

Detects faces in cached thumbnails using RetinaFace + MobileFaceNet (ONNX). Per-asset, opt-in. The worker needs both ONNX model files; drop them in the model directory below or set the download URLs and the worker fetches them on first boot.
