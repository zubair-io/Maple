Push notifications (Apple devices)

The Files app extension on iPhone/iPad/Mac normally keeps a persistent connection open to notice changes, which costs a small amount of battery in the background around the clock. Turning this on switches it to Apple push notifications instead: the server pushes a silent wake-up only when something actually changed, so the extension can stay fully idle the rest of the time. The persistent connection remains the fallback whenever this is off, or on but not yet usable (see below).
