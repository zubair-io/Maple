Worker authentication

The Cloudflare Worker that fronts thumbnail requests validates the same bearer tokens this server issues. It needs the server's JWT signing secret, which this app does not display — retrieve it directly from the server (MongoDB server_state collection, _id: "jwt_secret", field value) and run wrangler secret put JWT_SECRET on the Worker.
