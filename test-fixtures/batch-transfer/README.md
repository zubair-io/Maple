# Batch transfer paired RAWs

These two tiny, valid Bayer DNGs are controlled sensor fixtures, generated by
`cargo run --release -p raw-core --features test-support --example gen-batch-transfer-fixtures -- ../../test-fixtures/batch-transfer`
from `src/raw-pipeline`. They are synthetic, not photographs from the performance corpus.
Both carry an identity camera matrix, distinct AsShotNeutral tags, and a two-dimensional
sensor gradient. The source is 96×64 landscape; the target is 80×120 portrait.

`pair.json` records each actual core estimator's baseline rounded to the editor's
50 K / integer-tint display domain. The authored correction is +1200 K / +10 tint.
Relative transfer means applying those numeric corrections to each asset's own
as-shot baseline; it does not claim an identical physical chromatic adaptation
at different starting temperatures. Absolute transfer remains the default.

The Web test renders the transferred target through the actual WASM core and
compares its pixels with an independently authored target correction. It also
requires an ordinary absolute copy to produce different pixels. The normalized
center crop must render to 40×60 on the target and equal the correct center of
its uncropped render; the source's same crop is 48×32. These pixel assertions
catch incorrect transfer or geometry even when copied scalar values look plausible.
