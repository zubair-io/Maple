# MapleWatch

Watch-native read-only browsing for #3617. Link this local Swift package into the watchOS 10+ app target. It depends on the portable `MapleCloudKit` product, never the Rust RAW framework.

`MapleWatchLibraryView(server:onSignOut:)` is the authenticated entry point. The caller supplies a paired server whose independent Watch tokens are already in `TokenStore`. Destroy/recreate the view when changing the authenticated session, including re-pairing the same server. Its Disconnect action clears credentials, cancels requests, invalidates its credential lease and image cache, then calls `onSignOut` to return to pairing. The same callback is delivered when refresh rejects the session.

The native navigation stack offers library selection, Recent Photos, Memories and collection photos. Pages contain at most 20 result records and replace prior pages; videos are omitted from display without altering server pagination offsets. Empty video-only pages still offer Next when the server has more results. Photo rows show 128-pixel thumbnails alongside filenames. Turn the Digital Crown or use the accessible Previous/Next buttons to browse the current page; go back to load another page.

Images come from the authenticated server thumbnail route, with the 1280-pixel preview route as a fallback on thumbnail fetch/decode failure. Both currently serve AVIF; the fallback recovers missing/bad thumbnails rather than promising a different codec. ImageIO transforms orientation and downsamples to at most 128 pixels in rows and 512 pixels in the viewer. An actor owns a strict 8 MiB decoded-image LRU keyed by server, asset path, source mtime and decoded thumbnail tier. It lives for the authenticated session and is invalidated at disconnect. Explicit Refresh clears decoded images and prevents earlier in-flight requests from repopulating stale sidecar-derived pixels, even when the original asset mtime is unchanged. Disconnect also clears the cache. HTTP uses an ephemeral session with URL caching disabled and two connections per host. A cancellation-aware semaphore bounds image fetch/decode work to two requests, including multiplexed HTTP/2 requests. Original files and XMP sidecars are never fetched or modified.

All screens show loading, empty and failure states, with explicit retry. If both derivatives fail, unsupported preview decoding is reported as an error; no original download fallback exists. AVIF decoding, Crown feel, VoiceOver, offline/reconnect, phone/Watch pairing, and sleep/token refresh need validation on the installed Watch simulator and physical hardware before shipping.

The credential-lease tests cover late refresh writes after logout, repeated expiry callbacks, and concurrent logout during persistence. HTTP-backed pagination tests also cover empty filtered memory pages with later results and truly empty collections. These non-UI tests can run on macOS in an isolated test target with the real MapleCloudKit sources. The complete SwiftUI package must be compiled against the watchOS SDK and exercised through the Watch app target.
