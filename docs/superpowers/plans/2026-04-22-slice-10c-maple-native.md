# Slice 10c — Maple native (iOS/Mac/iPad Swift)

**Goal:** Deliver a production Swift app that consumes `raw-core` via the `RawPipeline.xcframework`, runs a three-column shell on Mac/iPad and a bottom-tab single-column collapse on iPhone, and reads from PhotoKit / filesystem / SMB sources. Reuses the `.maple/` folder cache so thumbs generated by Maple Hosted / Self Hosted / a different native device all stay usable.

**Current state:** SPM scaffold at `src/maple-native/`. `swift test` runs one trivial smoke test. `MapleApp` renders a "Maple stub" placeholder view.

**Spec pointers:**
- `docs/spec/12-maple-apps-spec.md` § 09 (Maple native).
- `docs/spec/00-overview.md` "Apple (Swift)" and "Explicit stack inventory".
- `docs/spec/01-data-model.md` (EditSession, AdjustmentModel, CullingState types).
- `docs/spec/02-pipeline.md` (filter chain on Apple — CIFilter + custom CIColorKernel).

## Architecture

```
┌─────────────────────────────────────────────────────┐
│                    MapleApp (.swift)                 │
│     @main / WindowGroup / NavigationSplitView        │
│  ┌─────────┬──────────────────┬──────────────────┐  │
│  │ Source  │  Browse / Full   │   DetailPanel    │  │
│  │ sidebar │  image canvas    │   Info / Develop │  │
│  └─────────┴──────────────────┴──────────────────┘  │
└─────────────────────┬───────────────────────────────┘
                      │
              ┌───────▼────────┐
              │   MapleCore    │
              │  (this package)│
              │                │
              │ EditSession    │
              │ ImageEditPipeline
              │ XMPSidecarStore│
              │ Sources:       │
              │   PhotoKit     │
              │   Filesystem   │
              │   SMB (AMSMB2) │
              └───────┬────────┘
                      │
           ┌──────────▼──────────────┐
           │  RawPipeline.xcframework│
           │   staticlib + C header  │
           │   from raw-ffi          │
           └─────────────────────────┘
```

The `MapleApp` target is thin SwiftUI views; `MapleCore` holds all business logic + the xcframework dependency.

## Phases

### P1 — `RawPipeline.xcframework` build script (~3 days)
- Cargo build of `raw-ffi` for 4 targets:
  - `aarch64-apple-ios`
  - `aarch64-apple-ios-sim`
  - `aarch64-apple-macos`
  - `x86_64-apple-macos`
- `cbindgen` config to emit `RawPipeline.h` from the `raw-ffi` source.
- `xcodebuild -create-xcframework` to bundle the four staticlibs + headers.
- Drop result at `src/maple-native/Frameworks/RawPipeline.xcframework`.
- Uncomment the `.binaryTarget` line in `Package.swift`.

### P2 — Swift wrapper around the FFI (~3 days)
- `MapleCore.PipelineRenderer` struct: safe API around the three `#[no_mangle] extern "C"` functions.
- Handles `MapleImageBuffer` ownership (RAII: Swift wrapper deinits via `maple_free_buffer`).
- Thread-safety: FFI uses thread-local errors; Swift wrapper is `Sendable`.

### P3 — AdjustmentModel + XMP types in Swift (~3 days)
- Port `raw_core::xmp::AdjustmentModel` as a Swift `struct` with the same fields and defaults.
- XMP read via `raw_core::xmp::parse` from bytes (requires `raw-core` decode-from-bytes API first — same blocker as slice 10a P4).
- `XMPSidecarStore` actor: debounced writer, atomic temp-file rename, same byte form as Lightroom.

### P4 — EditSession + ImageEditPipeline (~1 week)
- `EditSession` per spec § 01: `asset`, `model`, `originalModel`, `decodedImage`, `renderedPreview`, `renderPhase`, zoom, undo/redo stacks.
- `ImageEditPipeline`: wraps the 11-stage filter chain per spec § 02, using CIFilter + the custom CIColorKernels (`SceneToneControls`, `SceneVibrance`, `AgXViewTransform`).
- Two-phase render: fast (viewport, 50ms) → refine (full-res, 300ms) per spec § 02 / § 05.

### P5 — Custom Metal kernels (~1 week)
- `SceneToneControls.metal` — CIColorKernel (replaces the Rust equivalent from slice 2).
- `SceneVibrance.metal` — Oklab chroma scale + skin window (slice 3).
- `AgXViewTransform.metal` — log encode + sigmoid (slice 1 + slice 6 once the Blender sigmoid lands).
- Numeric parity tests: CIColorKernel output vs. `raw-core` CLI output on the same XMP, within spec § 11 gate 4 tolerance (ΔE ≤ 1.0).

### P6 — Source adapters (~1 week)
- `FilesystemSource` — security-scoped bookmarks, folder picker via `NSOpenPanel` (Mac) / `.fileImporter` (iOS).
- `PhotoKitSource` — PHFetchResult, PHImageManager for RAW bytes.
- `SMBSource` — AMSMB2 Swift package; sidecar writes over SMB with retry logic.

### P7 — UI shell (~2 weeks)
- `AppShell` with NavigationSplitView (Mac/iPad) + TabView collapse (iPhone).
- Browse grid with lazy image loading, selection, culling keybinds.
- Full-image view with zoom + pan + before/after gesture.
- Detail panel: Info + Develop tabs with collapsible sections (match `src/maple-hosted/` prototype look).
- Design tokens ported from `src/maple-hosted/lib/tokens.jsx`.
- Keyboard shortcuts: stars 1-5, P/X flags, arrow navigation, ⌘E export.

### P8 — Caches (~3 days)
- `RenderedPreviewCache` — JPEG per-asset on disk; key = (primaryURL hash, sidecar mtime, screen size).
- `ThumbnailDiskCache` — shared format with Maple Hosted / Self Hosted (`.maple/` folder).
- `LibraryIndex` — per-folder JSON cache for cold-folder open performance.

### P9 — Export (~3 days)
- NSSavePanel on macOS; iOS share sheet (spec deferred this — land a basic version here).
- Formats: JPEG sRGB, JPEG P3, HEIC P3, TIFF 16-bit, PNG. (Matches slice 8.)
- Tiled render for > 50 MP images per spec § 02 Trace C.

### P10 — App Store packaging (~1 week)
- Icon set, launch screen.
- Info.plist entries: PhotoKit usage, SMB usage, security-scoped bookmarks entitlement.
- TestFlight distribution.
- Bundle ID `app.justmaple.Maple-Maple` per spec § 00.

## Deliverables

- `swift build` produces a working macOS app (iPad/iOS requires Xcode signing).
- Opens a folder or PhotoKit library, renders RAWs end-to-end through the native CIFilter chain, writes XMPs back to disk.
- ΔE parity with CLI within spec § 11 gate 4 budget.

## Open questions

- **GPU render precision.** Metal f32 parity with Rust f32 should be exact, but Core Image may internally downgrade to f16 depending on the pipeline. Measure at P5.
- **Universal binary on Intel Macs.** x86_64 is in the xcframework targets. Worth keeping until Apple drops Intel support entirely?
- **AMSMB2 licensing.** Dep review before App Store submission.
- **visionOS.** Spec calls out scaffold only, deferred. Skip entirely from P10 packaging.

## Estimated total: 5-7 weeks for a single engineer, iPhone/iPad/Mac parity.
