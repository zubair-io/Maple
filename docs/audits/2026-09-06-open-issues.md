# Maple open-issue audit — 2026-09-06

Scope: 108 open issues; 30 Apple-specific issues excluded; 78 non-Apple or shared issues assessed. Read 14 open PRs, all 1,660 historical PR summaries, live remote branch heads, local branches/worktrees, and the latest two comments plus recent cross-reference timeline for every in-scope issue. Product code reference is origin/main 84ff5fffd (before the fixes produced in this task). This is a dated audit snapshot; GitHub issues remain the live source for status and follow-up work.

A PR mention is not proof that all acceptance criteria are implemented. Historical branches are explicitly distinguished from active PRs. No observed work means no matching open PR, visible issue-linked branch, or matching local branch/worktree was found; it cannot rule out unpushed work, private forks, or branches with unrelated names. Large proposals marked candidates have not all received full code/fixture audits, and are not declared ready to merge.

## Immediate decisions

- #3318 was a confirmed unclaimed accessibility defect. This task implements keyboard and assistive-technology activation of Undo, with regression coverage for synthetic clicks, pointer clicks and long-press redo.
- #3335 is confirmed Web/Windows XMP data loss. Defer complete implementation until active PRs #3280, #3281 and #3285 land: typed hue/range mirrors and the four-writer fixture depend on them. Copying unknown attributes is insufficient because current readers fold CorrectionAmount into known sliders, while writers emit amount 1; an unchanged LocalHue would then change its effective value.
- #3315 is still a real report but its suggested endpoint patch was retracted. The latest investigation points toward IP policy; no endpoint change should land without reproduction.
- #3313 and the Web/API portions of #3311 are the clearest remaining product follow-ups with explicit unimplemented acceptance from merged PRs.
- #870, #2317, #1741, #1478 and #828 merit closure, rescope or evidence reconciliation; adding code merely to satisfy their old bodies would duplicate work or address a disproven premise.
