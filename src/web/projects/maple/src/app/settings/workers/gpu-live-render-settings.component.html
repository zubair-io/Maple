gpu-live-render {{ statusLabel() }} {{ summaryLine() }}

Routes the browser editor's live render through the wgpu + WGSL GPU chain instead of the threaded-CPU render_bytes path. Turning it off is the runtime kill switch: no redeploy, no restart. Open clients pick the change up within a minute and switch on the next image they open; a reload applies it instantly. Browsers without WebGPU, and any browser whose GPU adapter fails, already fall back to the CPU path on their own.
