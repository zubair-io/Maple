Maple · Interaction Specification

A photo library and non-destructive editor

version 0.1 (draft)
owner Design

TL;DR

Maple is a dark, keyboard-first desktop app for culling and developing RAW photos. It has two top-level modes — Browse (justified grid of a folder's contents) and Full (single image with a filmstrip). A right-hand inspector holds Info and Develop tabs. All edits are non-destructive and persist to an XMP sidecar. Selection, ratings, flags, adjustments, and UI state (open panels, tab, thumb size) live in local state today; this spec defines the persistence boundaries, interactions, and keyboard contract so the app behaves predictably across mode and navigation changes.

01Concepts & data model

Entities

Image
A single photograph. Has a file (.CR3, .NEF, etc.), intrinsic dimensions w×h, EXIF metadata (camera, lens, focal, aperture, shutter, ISO, capture date), GPS, and a derived aspect ratio ar = w/h.
Sidecar
.xmp written next to the source file. Holds ratings, flags, color label, IPTC, keywords, and the full adj adjustment set. Source files are never written to.
Flag
One of pick none reject. Exactly one per image.
Rating
Integer 0–5. 0 = unrated.
Color label
One of red · orange · yellow · green · blue, or null.
Adjustments
The adj struct (see §07). A single flat object per image; absence ⇒ defaults.
Source
The current collection in view — a folder, a smart album (All, Favorites, Picks, Rejects), or a user album. Drives what appears in the grid and filmstrip.

Identity

Every image has a stable integer id. id is the only thing stored in selection / active-image state — never file paths or indices.

Contract: Mode is persistent across reload. On boot, the app restores the last mode and — if full — opens the previously active image. If that image is missing from the current source, fall back to browse.

Panel visibility

The tree/filmstrip (left) and the inspector (right) each toggle independently. Hidden panels animate width to 0 over 220ms; content fades to avoid ugly reflow.

  • ⌥⌘S — toggle left panel
  • ⌥⌘D — toggle inspector

03Left panel

Browse — folder tree

Two top-level sections, each collapsible. Section chevrons rotate down when expanded.

  1. Folders. A nested file tree. Folders can be expanded/collapsed; count badges are right-aligned in the SF Mono digits style. Hovering a section header reveals a ＋ affordance for adding a folder.
  2. Photos Library. Smart albums (All Photos, Favorites, Picks, Rejects) followed by a subheader and user albums.

Selecting any node sets source, which re-drives the grid. The selected row uses the accent tint; its folder icon, label, and count all recolor.

Full — filmstrip

Vertical 52×40 thumbnails, 4px gaps. The active image gets a 1.5px accent outline (inset, so it doesn't change layout). When activeId changes, the strip smooth-scrolls to center the active thumb inside the filmstrip viewport only — never the page.

Edited images show a 7px green dot in the top-right of the thumb.

Justified grid

Rows fill the container width while preserving each image's aspect ratio. Algorithm:

  1. Target height H = thumbSize. Gap G = 3px.
  2. Accumulate aspect ratios into a row until sum(ar) · H + (n−1) · G ≥ 0.92 · containerWidth.
  3. Close the row. Row height h = min(1.4 · H, availW / sum(ar)); thumb width = ar · h.
  4. Last row renders at target height without scaling.

Resize is observed with ResizeObserver; rows re-flow on every size change.

Thumb interactions

  • Click — sets selected = [id], sets activeId = id.
  • ⌘/Ctrl-click — toggles id in selected; activeId = id.
  • Shift-click — range-select from the last item in selected to id within the filtered list.
  • Double-click — opens image in Full mode.

05Full mode

Canvas

Letterboxed image, centered in the canvas, with a max dimension of 92% of the canvas in the dominant axis. Zoom is applied via transform: scale(z) with a 220ms ease (cubic-bezier(0.22, 1, 0.36, 1)). Zoom range [1, 4] in steps of 0.25; z == 1 renders as Fit in the chrome.

A subtle, blurred filename pill sits top-center as a contextual overlay — it's separate from the chrome title and does not disappear when the panel is hidden.

Before / after

A draggable vertical divider overlays a desaturated, slightly-darkened copy of the image on the left of the divider. Divider position clamps to [0.05, 0.95]. BEFORE / AFTER chips sit in the top corners.

Empty state

If there is no active image, Info renders a centered muted label: Select an image to see details.

Multi-select

When selected.length > 1, editable fields dim; rating/flag/color-label actions apply to the whole selection. (Out of scope for v0.1: mixed-value indicators — see §13.)

Behavior

  • Scopes (histogram + live waveform/vectorscope) pin to the top of the tab in Full mode.
  • Sliders are double-click-to-reset. Drag to edit; arrow keys on a focused slider nudge by step.
  • White-balance presets set temp+tint to fixed values. Selecting Custom doesn't mutate values, only the label. Pick neutral enters an eyedropper pick mode (out of scope for v0.1 — see §13).
  • Sticky action row at the bottom: Revert (restores DEFAULT_ADJ), Copy (stash adj to clipboard slot), Paste (apply stashed adj over the current image, deep-merged).

Persistence

Adjustments are in-memory only today. v0.1 ships with adj persisted per id and serialized into the XMP sidecar on save (debounced 500ms after last edit).

08Selection model

Selection is distinct from active image.

selected: id[]
Ordered array. Determines bulk actions and the counter label. Cleared when source changes.
activeId: id
The image shown in Full mode and the inspector. Always the most-recently-interacted member of selected; if selected is empty, it may still point at an id (e.g. last viewed).

Rules

  1. A plain click sets selected = [id] and activeId = id.
  2. ⌘/Ctrl-click toggles id in selected; activeId always becomes id.
  3. Shift-click extends the range within the current filtered list from the last element of selected to id.
  4. Arrow navigation in Full mode replaces selected with a one-element array [activeId], by design — arrowing through images shouldn't build up a large selection.
  5. When the filter is changed, selected is not pruned. Off-list items remain in selected but are not visible; the counter is correct because it's based on selected.length, not filtered membership.

09Keyboard contract

Handlers are registered on window. They no-op when focus is inside INPUT or TEXTAREA.

KeysModeAction
EnterbrowseOpen activeId in Full.
EscfullReturn to Browse.
← →fullPrevious / next image in filtered list.
0–5bothSet rating on activeId. 0 clears.
PbothToggle pick on activeId.
XbothToggle reject on activeId.
⌥⌘SbothToggle left panel.
⌥⌘DbothToggle inspector.

Rating via keyboard writes to a per-image override map (ratings[id]); the source image's static stars is used as a fallback only. Same for flags[id]. This two-layer pattern is load-order safe — the app can render immediately from bundled image metadata while overrides hydrate from storage.

Collapsible state

Each MapleCollapsible instance persists under its own storageKey (info-file, info-camera, dev-tone, etc.). No umbrella key.

Tweaks (design-time only)

The Tweaks panel surfaces an EDITMODE JSON block for accent color, sidebar variant, grid density, and border contrast. It posts changes to the host with __edit_mode_set_keys; those are development-time design controls, not user preferences, and MUST not leak to shipping builds.

12Export

The single Export button lives in the titlebar. Behavior:

  • Disabled (50% opacity, muted color, default cursor) when selected.length === 0.
  • Enabled — accent fill on primaryDim with primary border — otherwise. Label is Export for one image, Export (n) for more.
  • v0.1 opens an export sheet with format (JPEG / HEIC / PNG / TIFF / original), size preset, sharpen-for-output, destination, and filename template. Sheet UI is not covered in this spec; eng may stub it as a modal.

13Open questions

  1. Multi-select field display. In the inspector, mixed values need a visual (e.g. — or 〈multiple〉). Not designed yet.
  2. White-balance eyedropper. The UI affordance exists; the pick-mode cursor, crosshair, and sampling radius are unspecified.
  3. Drag-and-drop between folders in the tree, and from filmstrip/grid onto folders. Scope for v0.2.
  4. Import pipeline. How folders are scanned, thumbs cached, and sidecars discovered is out of scope here.
  5. Rating vs flag precedence when filtering — we currently apply flag filter to flag override OR original; picks filter doesn't honor rating. Confirm desired semantics for future compound filters.
  6. Undo. No undo stack today. Per-slider undo via history snapshots exists but global undo (selection, flag, rating) is not wired.
