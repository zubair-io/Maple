Maple offline testing model bundle — modified model exports (#1472 / #3941).

These ONNX artifacts are Maple conversions, not upstream ONNX releases.
LaMa: source advimman/lama; learned generator tensors from big-lama;
complex Fourier operations replaced with portable standard ONNX DFT.
MobileSAM: fixed photographic encoder input; dynamic prompt decoder; all
four upstream candidates retained. RT-DETRv2: deployed R18 graph and
postprocessor exported with upstream evaluation input conventions.
See the exact source revisions, checkpoint/artifact hashes and toolchains
in the accompanying export records. No new model training is performed.
