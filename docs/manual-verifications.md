# Manual verifications — human-gate log

Tasks whose verifier requires eyeballing a render, observing on-device behavior, or otherwise cannot be a deterministic shell command live here. The agent halts when it reaches a row and waits for the user to sign it. The agent never signs its own rows.

Each row:

- **Task** — task ID from `tasks.md`
- **Check** — what the human must verify
- **Artifact(s)** — where the output to inspect lives (paths relative to repo root)
- **Signed by** — user's initials + date in `YYYY-MM-DD` form; empty until signed
- **Notes** — observations recorded during the check (optional)

Agent must not mark a row "signed by <agent>" or self-sign. If the human chooses not to sign (the check failed), the agent treats the row as unsigned and either iterates on the underlying task or writes `BLOCKED.md`.
