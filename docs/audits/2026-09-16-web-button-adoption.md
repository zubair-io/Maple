# Remaining Web button adoption — #3664

## Scope and result

Snapshot: `e226da2d2`, before this PR. An HTML-parser scan of `src/web/projects/**/*.html`, excluding `/ui/`, `/gallery/` and `ui-gallery`, found **98 raw button tags in 44 templates**. Counts describe static tags, including loop bodies, not rendered instances. HTML comments are excluded. Line numbers below refer to that snapshot; migrations can move them.

The LAN offer is the first bounded migration: two ordinary actions use `MuiButton`, with its template added to the existing adoption ratchet. This leaves **96 raw tags in 43 templates**. A raw tag is not automatically a defect: replacing tile, form, tab, menu or gesture controls mechanically would change behavior.

Classification totals (including the two migrated entries): **59 candidate**, **28 retain**, **9 contract gap**, **2 migrated**. Every baseline tag appears exactly once below. “Candidate” means a component-contract match, not that a migration has passed runtime or visual validation. “Retain” records the concrete interaction requiring a coordinated organism migration. “Contract gap” identifies missing forwarding on the inner native control; putting attributes on the Angular host does not solve it.

## Tracking and migration order

- [#3697](https://github.com/zubair-io/Maple/issues/3697): 14 batch metadata/rename actions; medium, complexity 2/5.
- [#3698](https://github.com/zubair-io/Maple/issues/3698): seven Trash actions, including native `aria-describedby` support; medium, complexity 2/5.
- Other candidates and retained interactions remain in adoption epic [#3019](https://github.com/zubair-io/Maple/issues/3019). These are inventory entries, not a claim that the epic is complete. Prior waves [#3029](https://github.com/zubair-io/Maple/issues/3029), [#3031](https://github.com/zubair-io/Maple/issues/3031), [#3046](https://github.com/zubair-io/Maple/issues/3046) and [#3047](https://github.com/zubair-io/Maple/issues/3047) are historical context, not reopened tickets.

Follow-ups are deliberately bounded to verified gaps; no blanket raw-button prohibition is introduced. Ratchet each template only after all incompatible semantics in it are handled. Shared button source and [contract](../design/maple-ui/components/button.md) are authoritative: it currently supports native labels/pressed/expanded/haspopup, but not submit type, controls, descriptions or keyshortcuts. Contract extensions should be driven by the specific consumers above.
