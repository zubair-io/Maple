## Task 1: Refactor `serialize(model:culling:metadata:)` to use a native builder

The current implementation in `XMPSerialization+MetadataWrite.swift` calls `serialize(model:culling:)`, receives a fully-rendered XML string, then string-patches three injection points: namespace declarations (after `xmlns:papp=…`), attributes (before `/>` or before the keyword block), and nested blocks (before `</rdf:Description>`). This is correct and tested today but fragile to any whitespace or ordering change in the base serializer.

The refactor extracts the attr-list construction from `serialize(model:culling:)` into an internal `_buildAttrs(model:culling:)` helper that returns `[(String, String)]`. Then `serialize(model:culling:metadata:)` calls `_buildAttrs`, appends metadata attrs, and renders the full template in one pass — no string-patching.

**Files:**
- Modify: `src/apple/Packages/MapleCore/Sources/MapleCore/XMPSerialization.swift` (extract `_buildAttrs`)
- Modify: `src/apple/Packages/MapleCore/Sources/MapleCore/XMPSerialization+MetadataWrite.swift` (rewrite `serialize(model:culling:metadata:)`)
- Test: `src/apple/Packages/MapleCore/Tests/MapleCoreTests/XMPMetadataTests.swift` (existing tests must pass; add a byte-stable-rebuild test)
- Test: `src/apple/Packages/MapleCore/Tests/MapleCoreTests/XMPSerializationTests.swift` (existing tests must pass)

**Interfaces:**
- Produces: `internal static func _buildAttrs(model: AdjustmentModel, culling: CullingState) -> [(String, String)]` on `XMPSerializer` — the same ordered attr pairs the base serializer currently assembles inline.
- Produces: `internal static func _buildKeywordsBlock(culling: CullingState) -> (dcNs: String, block: String)` — the two string pieces the base serializer currently builds inline.

```swift
/// Build the dc:subject keywords block pieces.
/// Returns the namespace suffix string (empty or `\n      xmlns:dc=…`)
/// and the block body (empty string or the multi-line `<dc:subject>…` block).
static func _buildKeywordsBlock(culling: CullingState) -> (dcNs: String, block: String) {
    guard !culling.keywords.isEmpty else { return ("", "") }
    let dcNs = "\n      xmlns:dc=\"http://purl.org/dc/elements/1.1/\""
    let liItems = culling.keywords
        .map { "          <rdf:li>\(escapeXMLText($0))</rdf:li>" }
        .joined(separator: "\n")
    let block = """

          <dc:subject>
            <rdf:Bag>
        \(liItems)
            </rdf:Bag>
          </dc:subject>
        """
    return (dcNs, block)
}
```

- [ ] **Step 3: Rewrite `serialize(model:culling:metadata:)` in MetadataWrite.swift**

Replace the string-patching body with a native builder:

```swift
public static func serialize(
    model: AdjustmentModel,
    culling: CullingState,
    metadata: XmpMetadata
) -> String {
    let metaAttrs = metadataAttrParts(metadata)
    let metaBlocks = metadataNestedBlocks(metadata)
    let prefixes = metadataNamespacePrefixes(metadata)

    // If nothing to add, return the base sidecar unchanged.
    guard !metaAttrs.isEmpty || !metaBlocks.isEmpty else {
        return serialize(model: model, culling: culling)
    }

    // Build the full attr list: adjustment+culling attrs first, then metadata.
    var attrs = _buildAttrs(model: model, culling: culling)
    attrs += metaAttrs.map { ($0.0, escapeXMLAttr($0.1)) }

    let attrsStr = attrs.map { "\($0.0)=\"\($0.1)\"" }.joined(separator: "\n        ")

    // Keywords block (dc:subject).
    let (kwDcNs, keywordsBlock) = _buildKeywordsBlock(culling: culling)

    // Namespace declarations for metadata prefixes, in fixed order.
    let nsOrder = ["dc", "exif", "photoshop", "Iptc4xmpCore", "xmpRights"]
    let hasDcKeywords = !culling.keywords.isEmpty
    let extraNsLines = nsOrder
        .filter { prefixes.contains($0) && !($0 == "dc" && hasDcKeywords) }
        .compactMap { p -> String? in
            guard let uri = xmpMetadataNamespaces[p] else { return nil }
            return "\n      xmlns:\(p)=\"\(uri)\""
        }
        .joined()

    // Build nested content: keywords block + metadata nested blocks.
    let metaNestedStr = metaBlocks.joined(separator: "\n")
    let allNested = keywordsBlock.isEmpty
        ? metaNestedStr
        : keywordsBlock + (metaNestedStr.isEmpty ? "" : "\n" + metaNestedStr)

    if allNested.isEmpty {
        return """
        <?xpacket begin="\u{FEFF}" id="W5M0MpCehiHzreSzNTczkc9d"?>
        <x:xmpmeta xmlns:x="adobe:ns:meta/">
          <rdf:RDF xmlns:rdf="http://www.w3.org/1999/02/22-rdf-syntax-ns#">
            <rdf:Description
              xmlns:crs="http://ns.adobe.com/camera-raw-settings/1.0/"
              xmlns:xmp="http://ns.adobe.com/xap/1.0/"
              xmlns:papp="http://ns.justmaple.app/1.0/"\(extraNsLines)
              \(attrsStr)/>
          </rdf:RDF>
        </x:xmpmeta>
        <?xpacket end="w"?>
        """
    } else {
        return """
        <?xpacket begin="\u{FEFF}" id="W5M0MpCehiHzreSzNTczkc9d"?>
        <x:xmpmeta xmlns:x="adobe:ns:meta/">
          <rdf:RDF xmlns:rdf="http://www.w3.org/1999/02/22-rdf-syntax-ns#">
            <rdf:Description
              xmlns:crs="http://ns.adobe.com/camera-raw-settings/1.0/"

              xmlns:papp="http://ns.justmaple.app/1.0/"\(kwDcNs)\(extraNsLines)
              \(attrsStr)>\(allNested)
```

## Task 2: Align `xmpRights:Marked` nil/omit with TS reference

The TS `copyrightStatusFromMarked` returns `null` for any value other than `"True"` or `"False"` (including unknown strings). The Swift parser currently maps unknown `xmpRights:Marked` values to `.unknown` (`default: metadata.copyrightStatus = .unknown`). This means a sidecar with `xmpRights:Marked="garbage"` sets `copyrightStatus` to `.unknown` on Apple but leaves it as `null`/`nil` on TS. The fix: change the `default` arm to `break` (leave `copyrightStatus` as `nil`).

## Task 3: Restrict altitude parsing to canonical digit-rational form

The Swift `altitudeFromXmp` uses `Double()` on each side of the `/` separator, which accepts floating-point values like `35.5/1.0` and signed values like `-35/1`. The TS reference uses regex `^(\d+)\/(\d+)$` — digits only, no sign, no decimal point. Both parsers only ever encode integer-numerator values (`1000ths`, so the numerator is always a non-negative integer). Making Swift match the TS restriction means rejecting non-canonical forms and being explicit about the accepted format.

**Files:**
- Modify: `src/apple/Packages/MapleCore/Sources/MapleCore/XMPSerialization+Metadata.swift` (`altitudeFromXmp` function)
- Test: `src/apple/Packages/MapleCore/Tests/MapleCoreTests/XMPMetadataTests.swift` (add tests for non-canonical forms)

- `public func altitudeFromXmp(value: String, ref: String) -> Double?` — signature unchanged, behavior restricted

```swift
/// Decode an altitude rational + ref back to signed meters; `nil` if malformed.
/// Accepts only the canonical `\d+/\d+` form (digits only, no sign, no decimal
/// point) — matches the TS `altitudeFromXmp` regex `^(\d+)\/(\d+)$`.
/// The sign is encoded in `ref` ("0" = above sea level, "1" = below).
/// Mirrors `altitudeFromXmp` in `xmp-metadata.ts`.
public func altitudeFromXmp(value: String, ref: String) -> Double? {
    let pattern = try? NSRegularExpression(pattern: #"^(\d+)\/(\d+)$"#)
    let trimmed = value.trimmingCharacters(in: .whitespaces)
    guard let m = pattern?.firstMatch(
        in: trimmed,
        range: NSRange(trimmed.startIndex..., in: trimmed)
    ) else { return nil }
    guard
        let numRange = Range(m.range(at: 1), in: trimmed),
        let denRange = Range(m.range(at: 2), in: trimmed),
        let numerator = Double(trimmed[numRange]),
        let denominator = Double(trimmed[denRange]),
        denominator != 0
    else { return nil }
    let meters = numerator / denominator
    return ref == "1" ? -meters : meters
}
```
