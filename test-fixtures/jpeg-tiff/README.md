# JPEG-compressed TIFF regressions

Generated by `bun tools/regenerate-jpeg-tiff-fixtures.ts` using Sharp 0.34.5
(libvips 8.17.3). Each TIFF uses Sharp's default JPEG compression and YCbCr
photometric. The matching `.rgb` is Sharp's decoded interleaved RGB8 output,
without auto-orientation. Sources are deterministic synthetic RGB gradients.

Cases cover multiple strips, multiple tiles with padded right/bottom edges,
BigTIFF tiles, quality 40/95, and TIFF orientation 6. Rust tests need no Sharp
installation: they read these committed fixtures and the independent decoded
pixel oracle. They also generate complete-JPEG strips without JPEGTables and
mutate container/JPEG headers to exercise error handling and allocation guards.
