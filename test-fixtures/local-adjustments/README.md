# Local-adjustment references

`spatial-radial.xmp` exercises Maple's spatial controls in a single radial correction.

`lightroom-group-add.xmp` is a Lightroom Classic 15.6 / Camera Raw 18.7 saved mask-group reference captured on 2026-10-01 for #3408. A hand-authored seed containing one radial and one linear component was embedded into a disposable copy of `test_0017.dng`, imported with Read Metadata from File in an isolated temporary catalog, then saved with Lightroom's Save Metadata to File. The fixture contains the saved `MaskGroupBasedCorrections` subtree verbatim; unrelated image, creator and catalog history metadata was omitted. The wrapper retains the saved Camera Raw and process versions. The source RAW was never modified (SHA-256 `26be5e06dfb53a2938dab3ca8f06024533a9c0dd0c652938f39eb48bc325f95e`).

Both components are additive: `MaskBlendMode=0`, `MaskValue=1`, `MaskInverted=false`. This fixture verifies Lightroom's accepted structure and serialization, not a Lightroom-authored drawing or subtract/intersect operation, and it is not a pixel-parity oracle. The seed's legacy radial feather/inversion was normalized by Lightroom to `Feather=25`, `Flipped=true`, `Version=2`; those saved fields must be interpreted according to that version. CPU/GPU composition qualification remains required before #3408 is complete.

`lightroom-group-subtract.xmp` and `lightroom-group-intersect.xmp` use the same imported radial component. The seeded additive linear component was deleted in Lightroom. A new linear gradient was drawn through Tools → Subtract from Mask with → Linear Gradient, saved, undone, then drawn through Tools → Intersect Mask with → Linear Gradient and saved. Both gradients were authored by Lightroom, not seeded. The saved correction subtrees are verbatim, with the same metadata omissions and wrapper as the additive reference. Subtraction writes `MaskBlendMode=1`, `MaskValue=0`, `MaskInverted=false`; intersection writes the same mode/value with `MaskInverted=true`. `MaskSubType` is absent from these geometric components and does not encode their combine operation. These exports establish serialization; they do not yet establish soft-edge blend mathematics or pixel parity.

The exports are structural fixtures. Independent Adobe pixel qualification of the local controls and soft-edge coverage is tracked by #1478; neither a successful XMP round trip nor CPU/GPU agreement supplies that oracle.
